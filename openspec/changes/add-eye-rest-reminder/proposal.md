## 为什么需要这个变更

长时间连续面对屏幕容易让用户忽略休息时间。keep-eyes 需要提供一套简单、明确且不会妨碍正常工作的 Windows 护眼提醒流程：在用眼时间结束前先以位于活动显示器顶部的透明、置顶、紧凑面板提醒用户主动处理；用户确认开始休息后，应用再关闭显示器以减少继续观看屏幕的干扰。显示器被唤醒不代表休息完成，休息仍由独立倒计时管理。

## 变更内容

- 新增 Windows 桌面护眼提醒应用的核心计时、休息和提醒流程。
- 支持保存用眼间隔、休息时长、延后提醒时长和提前提醒时间；提前提醒默认 30 秒，支持设置为 0～300 秒。第一版不提供提醒方式选择、温和通知或 Windows 锁定选项。
- 距离用眼时间截止达到提前提醒时间时，在活动显示器顶部显示由透明原生窗口承载、具有清晰半透明底色与描边轮廓、置顶且不抢夺焦点的紧凑提醒面板；非按钮区域保持鼠标穿透，面板显示距离本轮休息的实时剩余时间，并提供开始休息、延后、暂停、“知道了”和“跳过本次休息，继续当牛马”。“知道了”仅隐藏面板且不改变原定截止时间；“跳过本次休息，继续当牛马”则取消本次休息、不关闭显示器，并从点击时刻开始一轮完整的用眼计时。用户未处理时，用眼截止到达即自动开始休息。
- 用户选择开始休息，或在提前提醒后直到用眼截止仍未操作时，应用开始休息倒计时、关闭透明提醒层，并请求 Windows 关闭显示器；关闭显示器成功或失败都不改变休息计时。
- 用户通过鼠标或键盘重新亮起屏幕时，应用不得把该操作视为完成休息；仅在休息倒计时结束或用户明确提前结束休息后开始下一轮用眼计时。
- 提供系统托盘入口，用于查看状态、打开设置、立即开始休息、临时暂停提醒和退出应用。
- 在本地保存用户设置；应用每次启动或重启后都丢弃上次运行中的计时状态，并按当前设置重新开始一整轮用眼计时。
- 交付 Windows x64 的 `.exe` 安装程序，正式支持 Windows 10 x64 和 Windows 11 x64。安装程序必须允许用户选择安装路径，并提供 Windows 标准卸载入口；卸载时默认保留用户设置和本地数据，同时提供“删除全部设置和本地数据”的选项。

## 能力范围

### 新增能力

- `eye-rest-scheduling`：可配置的用眼计时、提前提醒、默认自动开始休息、延后、暂停、跳过本次休息、休息倒计时、显示器关闭后的休息保持和重启后重新开始计时行为。
- `eye-rest-alerting`：固定的透明置顶紧凑提醒、基于绝对截止时间实时显示提醒倒计时、“知道了”但保持原计划、跳过本次休息、开始休息后关闭显示器和屏幕唤醒后继续休息计时行为。
- `tray-and-settings`：系统托盘控制、时间设置页面、本地持久化以及 Windows 安装、卸载和本地数据清理行为。

### 修改能力

- 无。

## 影响范围

- 新增 Windows 桌面应用工程、主进程、渲染进程和受限预加载桥接层。
- 使用 Electron、React、TypeScript 和本地设置存储；核心计时状态机需要使用 Vitest 测试。
- 调用 Windows 显示器电源能力；不调用 Windows 工作站锁定能力。
- 第一版仅面向 Windows，不包含登录、后端服务、云同步或医疗诊断功能。
- 最终用户交付物为 Windows x64 `.exe` 安装程序；不支持 Windows 32 位、Windows 7/8/8.1，Windows ARM64 不属于第一版承诺范围。
