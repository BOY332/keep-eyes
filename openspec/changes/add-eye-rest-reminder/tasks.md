## 2. 提醒领域模型与持久化

- [ ] 2.1 定义并校验用眼间隔、休息时长、延后时长和默认 30 秒、范围为 0～300 秒的提前提醒时间；移除提醒模式、宽限时间、Windows 锁定同意和锁定场景保护等不再支持的设置及其持久化数据；确认单元测试覆盖有效值、无效值、旧数据迁移和重启后新计时策略。
- [ ] 2.2 实现可持久化的提醒状态模型和本地存储适配器，运行期间使用绝对截止时间和提前提醒状态驱动状态机；持久化用户设置但不把运行中的计时快照用于重启恢复；确认设置可以无损读取。
- [ ] 2.3 实现用眼计时、提前提醒展示、已延后、已暂停和休息计时状态机；确认单元测试覆盖提前提醒、用户无操作时用眼截止自动开始休息、所有合法状态转换，并阻止多个有效倒计时同时运行。
- [ ] 2.4 实现应用启动时忽略上次运行中的计时快照，按照已保存设置创建新的用眼计时；确认重启测试不会恢复待处理提醒、暂停或休息状态。
- [ ] 2.5 添加由主进程驱动的提醒调度器，使用绝对到期时间驱动状态机并保存状态；确认模拟计时器集成测试覆盖“用眼计时 → 休息 → 下一轮”的完整流程。

## 3. 主进程 Windows 集成

- [ ] 3.1 实现系统托盘及其菜单，提供打开应用、显示当前状态、开始休息、暂停提醒和退出应用操作；确认每个菜单操作都会调用对应的领域动作。
- [x] 3.2 实现统一专注提醒窗口控制器：在当前活动显示器顶部创建透明、无边框、置顶但不抢焦点的紧凑操作面板，不创建覆盖整个工作区的窗口；确认重复状态更新复用同一窗口、创建失败可明确处理、隐藏时关闭当前面板。
- [ ] 3.3 实现 Windows 显示器电源适配器，并在用户选择开始休息后请求关闭显示器；确认关闭显示器失败仍保持休息计时，且屏幕重新亮起不会完成休息。

## 4. 渲染进程用户体验

- [ ] 4.1 构建主状态页面，显示当前状态、基于绝对截止时间实时更新的剩余时间、提前提醒状态和固定专注提醒流程说明；用眼计时、已延后、已暂停和休息计时期间的可见倒计时至少每秒更新一次，并在窗口恢复或系统睡眠恢复后重新校准；确认页面可以渲染通过类型安全 IPC 获取的状态，并使用可控时间测试证明倒计时更新且不会累计漂移。
- [ ] 4.2 构建设置页面，仅支持用眼间隔、休息时长、延后时长和提前提醒时间；移除提醒模式、宽限时间、锁定 Windows 和锁定保护设置；确认无效输入显示校验反馈、有效设置可以保存，且页面说明固定提醒流程。
- [x] 4.3 构建透明、置顶且非阻塞的紧凑提醒面板，提供开始休息、延后、暂停和关闭操作；确认面板在提前提醒时间达到时以非激活方式显示，底层应用仍可继续操作，关闭后保持原定截止时间，用户无操作直到用眼截止时自动开始休息。
- [ ] 4.4 构建休息倒计时页面，显示剩余时间并提供明确的提前结束操作；确认用户开始休息后请求关闭显示器，倒计时结束和提前结束都能开始下一轮用眼计时，且亮屏不会结束休息。
